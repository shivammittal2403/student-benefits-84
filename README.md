# 84 Student Benefits & Free/Discounted Resources

A curated list of 84 student-oriented benefits, education plans, free tiers, developer resources, and discounts extracted from the provided screenshots.

> **Important:** Not every item below is a guaranteed universal student benefit. Some are regional offers, temporary promotions, general free tiers, GitHub Student Developer Pack offers, or education programs with separate eligibility rules. Always verify the current terms on the official page before relying on an offer.

## Current verification notes

- GitHub says the Student Developer Pack includes **80+ resources** for verified students, and partner offers can change over time.
- GitHub student eligibility generally requires being **13+**, enrolled in a degree/diploma-granting program, and providing academic email and/or proof of enrollment.
- Google currently advertises a **one-year Google AI student offer in India** for eligible college students.
- JetBrains currently provides a **free Student/Teacher Pack** for eligible students and teachers.
- Some screenshot claims such as generic “Cloudflare Pro”, “OpenAI API credits”, “Stripe credits”, or “PayPal credits” should not be treated as universal student entitlements without checking the provider’s current terms.
